# Mantle (Unofficial Port)  
**Shared code for NeoForge mods, updated for Minecraft 1.21.1.**

This is an unofficial port of the Mantle library mod, redesigned to maintain full compatibility with modern Minecraft rendering layers and the NeoForge ecosystem.

## Compile from Source
Note: Git MUST be installed and in the system path to use our scripts.
* **Setup:** Import as a Gradle project into your desired IDE (e.g., IntelliJ IDEA). Run `gradlew genIntellijRuns` to configure the workspace and setup launch configurations.
* **Build:** Run the wrapper in the repository root: `gradlew build`
* If obscure Gradle issues are found, try running `gradlew clean` or clearing the Gradle cache.

## Issue reporting  
When reporting issues for this specific port, please include the following:

* Minecraft version (`1.21.1`)
* Mantle port version
* NeoForge version/build
* Versions of any Mantle dependent mods (like Tinkers' Construct ports)
* Any relevant screenshots or crash logs (via Pastebin/Gist)
* Steps to reproduce the bug
